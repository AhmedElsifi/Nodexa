Practical Challenges

Apply your knowledge with hands-on tasks. Complete these challenges to solidify your understanding of core Node.js concepts.

Task 01

Create a Basic HTTP Server

Medium

Build a server using the core `http` module that responds to different routes with specific JSON payloads.

  • Listen on port 3000.
  • Handle GET requests to `/api/status`.
  • Return a 404 for unknown routes.
Task 02

Read and Write Files with 'fs'

Easy

Use the File System module to perform basic async read/write operations.

  • Read a JSON configuration file.
  • Append a timestamp to a log file.
Task 03

Build a Simple Event Emitter

Hard

Implement your own version of Node's core EventEmitter class from scratch to understand the observer pattern.

Requirements:

  • Implement `on(eventName, listener)` method.
  • Implement `emit(eventName, ...args)` method.
  • Implement `once(eventName, listener)` method.
  • Handle multiple listeners for a single event safely.
